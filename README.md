## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors bundled together with a universal loader called xcutorsLoader. It allows you to easily switch between multiple executors from a single interface.

### Is XCutors free to use?

Yes, XCutors and all included executors are completely free to download and use. There are no hidden fees or premium tiers.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Older versions like Windows 7 or 8 are not officially supported.

### Do I need to disable my anticomponent software?

Some anticomponent programs may flag executor files as potentially unwanted programs (PUPs). You may need to add an exception or temporarily disable real-time protection during installation. Always download from the official GitHub repository.

### How do I update XCutors or the executors?

The xcutorsLoader includes an auto-update feature that checks for new versions on launch. You can also manually download the latest release from the GitHub Releases page.

### Can I use my own custom Lua scripts?

Absolutely. You can paste scripts directly into the editor, load them from local .lua or .txt files, or browse the built-in script hub for popular community scripts.

### Why is injection or attachment failing?

Common causes include: Roblox not running, the executor not launched as administrator, or an outdated executor version. Make sure Roblox is open, run the executor as admin, and check for updates.

### Is there a community or support channel?

Yes, we have an active Discord server where you can get help, share scripts, report bugs, and stay updated on new releases. The invite link is available in the repository README.

### Are there any risks involved?

Using script executors may violate Roblox's Terms of Service and could result in account penalties. Use at your own risk and consider using alternate accounts for testing.

### Which executor should I choose?

Each executor has its strengths. Volt is known for speed and stability, Synapse Z offers broad script compatibility, Potassium has a lightweight footprint, and Wave provides a modern UI. Try each one and see which fits your needs best.
